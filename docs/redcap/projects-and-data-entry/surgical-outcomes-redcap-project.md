# Surgical Outcomes REDCap Project

!!! abstract "What this page tells you"
    For every research-consented patient, fill out these REDCap instruments in the surgical outcomes project: patient info, consenting/subject numbers, PEC epilepsy info, presurgical results, neuropsych, intracranial EEG, surgical treatment, and outcomes follow-up yearly for 3 years.

#### These fields should be filled out in REDCap for every patient consented to research

*   Patient information
*   Consenting and Subject Numbers
*   PEC Epilepsy Information (Patient Information)
*   PEC Presurgical Data Results
*   PEC Neuropsych Results
*   PEC Intracranial EEG
*   PEC Surgical Treatment
*   PEC Outcomes F/U
    *   _This should be done yearly for 3 years, as each surgical patient will be seen ~1x per year after surgery_
