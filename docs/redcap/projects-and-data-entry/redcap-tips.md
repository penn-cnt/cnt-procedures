# REDCap Tips

!!! abstract "What this page tells you"
    Two REDCap admin tips: assign users to Data Access Groups via User Rights > Data Access Groups, and fix users who cannot export certain fields by unchecking 'Remove All Identifier Fields' under their role's Data Export Rights.

**Adding someone to a data access group**

*   User rights (under Applications)➝Data Access Groups
    *   This shows you who is in each of the current data access groups
*   Here, you can create a new DAG or add a user to a current one
*   Under "Assign user to a group"➝find user in the "Assign user" toggle➝choose the DAG you want them assigned to in the box to the right. Click the blue box that says "Assign" when done

**If someone is not able to export certain fields**

*   User rights ➝ next to their username, click on "Role name" ➝ under "Data Export Rights" check off all the boxes under "Remove All Identifier Fields"
