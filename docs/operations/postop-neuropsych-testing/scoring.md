# Scoring

!!! abstract "What this page tells you"
    Test-by-test scoring rules for the neuropsych battery: how to compute each raw score (Benton SF-to-LF conversion, Digits 0/1/2 scoring, BNT counts first 30 as correct, QOLIE-10 reverse-scores items 2, 3, 9) and which remote desktop 'scoring' folder document or spreadsheet tab gives the norms.

**Brief Cognitive Status Exam (Orientation + Auditory Comprehension)**

*   Don't need to score
**Benton Facial Recognition Test – Short Form (SF)**

*   Every correct scored question / subpart of question is 1 point
*   Total the SF score and using the conversion on the left hand side of the record form, convert it to the LF score
*   Based on the pt's age/sex, add the correction as needed
*   Norm the final score based on the chart on the bottom of the record form
**WMS-III Faces I** **_(only do these if administered previously)_**
**Recognition Memory Test (Faces Subset)** **_(only do these if administered previously)_**
**WMS-IV Visual Reproduction I** **_(only do these if administered previously)_**
**Rey Complex Figure Test + Delay (RCFT)**

*   Using the guidelines in the "scoring" folder in the remote desktop, award 0, 0.5, 1, or 2 points for each item in the copy and delay
*   Norm the score using the Rey (16-85) tab in the excel spreadsheet in the "scoring" folder in the remote desktop
**WAIS-5 Digits (Forward, Backward)**

*   Add up the scores for forwards and backwards each (remember 0 is wrong numbers, 1 is right numbers + wrong order, and 2 is right numbers + right order)
*   Norm using WAIS-5 document in "scoring" folder of remote desktop
**WMS-IV Logical Memory I and II**

*   Each item remembered is 1 point
*   The raw score total is the sum of each story for part I and part II respectively
*   Norm using WMS-IV document in "scoring" folder of remote desktop
**WAIS-5 Matrix Reasoning**

*   Raw score is total of each item
*   Norm using WAIS-5 document in "scoring" folder of remote desktop
**Trails A + B (Oral)**

*   Raw score is the time ([sec.ms](http://sec.ms)) taken for each test
*   Norm using Oral Trails tab in the excel spreadsheet in "scoring" folder of remote desktop
**WAIS-5 Symbol Span**

*   Raw score is total of each item
*   Norm using WAIS-5 document in "scoring" folder of remote desktop
**BVMT-R (Form 1)**

*   Score using guidelines in "Scoring" folder in remote desktop
*   Raw score is the total of each trial
*   Norm using BVMT tab in the excel spreadsheet in "scoring" folder in remote desktop
**Phonemic/Letter Fluency (FAS)**

*   Raw score is the total number of things named across all three letters (F, A, S)
*   Norm using the Heaton Norms (Appendix C to get scaled score then Appendix D to get t-score based on race, age, and education)
**Semantic/Category Fluency (Animals)**

*   Raw score is the total number of animals named
*   Norm using the Heaton Norms (Appendix C to get scaled score then Appendix D to get t-score based on race, age, and education)
**Boston Naming Test**

*   Raw score is total number of items named (include the first 30 you didn't do as correct) either without any cues or a semantic cue only (phonemic cue correct doesn't count!)
*   Norm using BNT tab in excel spreadsheet in "scoring" folder of remote desktop
**NAB Naming Test**
**California Verbal Learning Test – 3 (CVLT-3) or** **_CVLT-3 Brief Form_**

*   Raw score is total number of correct words per trial
*   Norm using CVLT-3 Brief document in "scoring" folder of remote desktop
**Symbol Digit Modality Test (SDMT) (Oral)**

*   Raw score is the total number of correct scores (not counting 10 in practice)
*   Use the SDMT tab in the excel spreadsheet in the "scoring" folder in the remote desktop to norm
**BDI-FS**

*   Raw score is the total of each question
*   Norm using the self-report ranges in the "scoring" folder of the remote desktop
**GAD-7**

*   Raw score is the total of each question
*   Norm using the self-report ranges in the "scoring" folder of the remote desktop
**QOLIE -10**

*   Raw score is the total of each question divided by 10
    *   Note that the scores for questions 2, 3, and 9 are flipped!!
    *   Question 2: (1 = 6, 2 = 5, 3 = 4, 4 = 3, 5 = 2, 6 = 1)
    *   Question 3: (1 = 5, 2 = 4, 3 = 3, 4 = 2, 5 = 1)
    *   Question 9: (1 = 4, 2 = 3, 3 = 2, 4 = 1)
