# Running the Test

!!! abstract "What this page tells you"
    Before testing, review the pre-op neuropsych report in EPIC, print the summary sheet, forms, and instructions, label pages INITIALS_RIDXXX_MMDDYYYY, and open the PowerPoints. Administer tests in summary-sheet order, photographing patient drawings. Afterward, update the tracker, reimburse, score, and enter scores and photos in REDCap.

**Before the appointment begins:**

1. Review the patient's most recent pre-operative neuropsychology test in EPIC to determine which tests to administer
2. Print out:
    1. Summary Sheet
    2. All score/record forms you will administer
    3. All testing instructions (file locations can be found here: Contacting+Scheduling Patients ([Contacting & Scheduling Patients](contacting-and-scheduling-patients.md)))
3. At the top of each page you print, write out the patient specific ID in this format: PATIENTINITIALS\_RIDXXX\_TESTDATE (MMDDYYYY) (i.e. for John Doe, RID = 01, test date = 01/01/2000 → JD\_RID01\_01012000
4. Open all the powerpoints you need to administer the test battery and go to the page you should start on.

**During the appointment:**

1. Administer the testing battery IN ORDER according to the summary sheet, using powerpoints when necessary (indicated on the summary sheet)
    1. You will need to share/unshare your screen as needed so the patient can see the powerpoints
2. For tests that require the patient to draw on a piece of paper, you must ask the patient to hold up the paper they have drawn to the camera so you can take a photo

**After the appointment:**
\*Mark off on SCHEDULE TRACKERS ([Scan Scheduling Trackers (sEEG, 3T/fMRI, 7T)](../scheduling-trackers/scan-scheduling-trackers-seeg-3t-fmri-7t.md)) as you go\*

1. Reimburse the patient for participating in research Reimbursements *(retired page)*
2. Calculate raw and normative scores for the tests Scoring ([Scoring](scoring.md))
3. Add the raw and normative scores for the tests to REDCap
4. Upload the testing photos to REDCap
