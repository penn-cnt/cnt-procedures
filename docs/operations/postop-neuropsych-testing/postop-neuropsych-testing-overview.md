# Postop Neuropsych Testing: Overview

!!! abstract "What this page tells you"
    Overview of the post-op epilepsy research neuropsych battery for patients after lobectomy or ablation: always use the newest test versions; tests marked 'II' are delayed recalls given 20-30 minutes after part I. Links the Box summary sheet; forms and instructions live on the Remote Desktop.

**The postop neuropsych epilepsy research test battery is a specific set of tests administered to patients post-operatively (after destructive surgeries, i.e. lobectomy / laser ablation). Each test may have different versions (i.e. Matrix Reasoning has a WAIS-IV and WAIS-5 version) because the tests are updated and revised periodically. Although the postop neuropsych epilepsy research battery is utilized as a re-evaluation, we use the most up-to-date versions as the scores are comparable, even if the pre-operative test the patient received may have used an older version.**

**In the summary sheet, some tests have a "I" and "II" written next to it, with "II" being administered much later on in the battery. This is intentional, as these tests have an immediate recall and delayed recall portion, and the delayed recall ("II") must be administered about 20-30 minutes after the immediate recall.**
