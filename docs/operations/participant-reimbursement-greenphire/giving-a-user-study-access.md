# Giving a User Study Access

!!! abstract "What this page tells you"
    To give an existing Greenphire user study access, open a BEN Helps ticket with their name, email and Penn ID, request type Research Study, status 'Already set up', IRB number and study nickname, Rachel DeAngelis as administrator, and a comment naming the person and study.

*   Give Existing Greenphire User Access to an Existing Study:
    *   Open up a new ticket
    *   Enter in person's name, email address, and Penn ID.
    *   In request type, select “Research Study”
    *   In status, please select “Already set up in Greenphire using VISA ClinCards”
    *   Enter in the IRB protocol number
    *   Enter in the name of the study in “Study/Program Nickname”
    *   For “Name of Business Administrator” please put Rachel DeAngelis.
    *   Enter in the Estimated End Date.
        *   This is the fund end date. You can get this from Carolyn or your PI.
    *   **In the comments please put that you are requesting for \[First Name\] \[Last Name\] to be added to \[XXXXX\] study.**
        *   **“I want to give \[First Name\] \[Last Name\] access to the study/studies stated above.**
