# Creating a Greenphire Account

!!! abstract "What this page tells you"
    To open a Greenphire account for a new user, submit a BEN Helps ticket listing all IRB numbers needed (CRC: 819126, 818407, 849276, 858681), study nicknames (Localizing Epileptic Networks, Epilepsy & Tumor Biomarkers, LB3, MXene MRI Study), Rachel DeAngelis as administrator, plus a request comment.

*   Create a New Greenphire Account for Someone ( [https://benhelps.upenn.edu/support/catalog/items/65](https://benhelps.upenn.edu/support/catalog/items/65)[![icon](https://www.google.com/s2/favicons?domain=https%3A%2F%2Fbenhelps.upenn.edu%2Fsupport%2Fcatalog%2Fitems%2F65&sz=64)](https://benhelps.upenn.edu/support/catalog/items/65)[Upennbenhelps.upenn.edu/support/catalog/items/65](https://benhelps.upenn.edu/support/catalog/items/65)[![icon](https://www.google.com/s2/favicons?domain=https%3A%2F%2Fbenhelps.upenn.edu%2Fsupport%2Fcatalog%2Fitems%2F65&sz=64)](https://benhelps.upenn.edu/support/catalog/items/65)[Upenn](https://benhelps.upenn.edu/support/catalog/items/65)
*   [benhelps.upenn.edu/support/catalog/items/65](https://benhelps.upenn.edu/support/catalog/items/65) )
_This is NOT the same as giving an existing user access to a study; this is opening a new Greenphire account for a new user)_ 

*       *   Open up a new ticket
    *   Enter in your name, email address, and Penn ID.
    *   In request type, select “Research Study”
    *   In status, please select “Already set up in Greenphire using VISA ClinCards”
    *   In “IRB Protocol Number” put the IRB numbers of all the studies you need access to
        - [ ] For the CRC it will be: 819126, 818407, 849276, 858681, ~~833844~~,
*       *   In “Study/Program Nickname” please put the names of the studies you need access to
        *   For the CRC it will be: Localizing Epileptic Networks, Epilepsy & Tumor Biomarkers, LB3, MXene MRI Study, ~~CAPES~~,
*       *   Scroll down to “Name of Business Administrator” and put Rachel DeAngelis
    *   Enter in the Estimated End Date.
        *       *   This is the fund end date. You can get this from Carolyn.
                *   You can also pick an arbitrary date (I usually do 2/2028)
*       *   **In the comments section please explain that you are requesting a new Greenphire account**
        *   “I am requesting a new Greenphire account and I would like to be added to the studies listed above.”
*       *   For School/Center please select “40 Perelman School of Medicine (PSOM)”
    *   Once all of the necessary information is entered, you can then select “Place Request” in red in the upper right-hand corner.
