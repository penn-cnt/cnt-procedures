# Ordering Physical Cards

!!! abstract "What this page tells you"
    The lab uses only virtual ClinCards (patient just needs an email); physical cards and other requests go through the BEN Helps Greenphire form or Greenphire support. Notes the 7T protocol 818407 end date 2/28/26 and that the 3T and 7T studies share one fund code (ask the PI for it).

**TO ORDER PHYSICAL CARDS:**  

[benhelps.upenn.edu](https://benhelps.upenn.edu/support/catalog/items/65)

**Ticket:**

[support.greenphire.com](https://support.greenphire.com/)


*   The lab is currently using only virtual clincards. For this, you just need the patient’s email to send the card to them. The email sent to the patient will include detailed instructions on how to use the card and access the money. Patients can transfer the money to their bank account if interested.
*   This SOP will include: checking the current budget in the account, registering a patient, assigning a subject number to them using REDCap, assigning a clincard to them, and loading the money onto the clincard.
*   This SOP will also show how submit a BEN Helps support ticket which is done to:
    *   Increase the study budget
    *   Give an existing Greenphire user access to a study
    *   Create a new study
    *   Close a current study
    *   Create a new Greenphire account for someone

**Protocol 818407 (7T MRI)-** end date is 2/28/26 (this is the current study end date so no need to refresh unless study gets extended)

Study fund code for both 3T and 7T: ask the PI or the business administrator (not kept on the wiki)
