# Adding Users to the ieeg.org Portal

!!! abstract "What this page tells you"
    Users create their own ieeg.org account; staff then add them to a project by opening its folder and checking their username under PROJECT ADMINS or PROJECT TEAM.

### Add to [ieeg.org](http://ieeg.org/)

1. Users can create their own account on the [ieeg.org](https://ieeg.org/) website
    1. Note: users are free to use any username/password they like
2. Once an account is created, staff can add a new user to a specific project by opening the project folder in [ieeg.org](http://ieeg.org/), then opening the "PROJECT ADMINS" and "PROJECT TEAM" headers, searching for their [ieeg.org](https://ieeg.org/) usernames (Ctrl+F), and marking the checkbox next to their usernames
