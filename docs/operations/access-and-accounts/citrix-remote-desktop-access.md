# Citrix Remote Desktop Access

!!! abstract "What this page tells you"
    Submit a UPHS IS ticket via pennmedaccess requesting the Remote Desktop Connection app be added to a staff member's Citrix Workspace; includes an email template with name, PennKey, and email fields.

1. Submit UPHS IS ticket and save the ticket number
    1. Login to: [https://pennmedaccess.uphs.upenn.edu/my.policy](https://pennmedaccess.uphs.upenn.edu/my.policy)
![PennMedicine Remote Access Portal employee resources tiles](../../assets/operations/citrix-remote-desktop-access/citrix-remote-desktop-access-01.png)

    1. Click "IS Self Service Portal" and then login to the UPHS IS Helpdesk
![IS Self Service Portal login, user asuncioj, masked password](../../assets/operations/citrix-remote-desktop-access/citrix-remote-desktop-access-02.png)

    1. Click "Create A Ticket"
![Penn Medicine IS Self Service Portal, empty recent requests](../../assets/operations/citrix-remote-desktop-access/citrix-remote-desktop-access-03.png)

    1. Click "Do You Need Something New?"
![IS Self Service Portal ticket type options and service catalog](../../assets/operations/citrix-remote-desktop-access/citrix-remote-desktop-access-04.png)

    1. Fill out the requester info. See screenshot for template
![IS portal requestor info form with staff name and location](../../assets/operations/citrix-remote-desktop-access/citrix-remote-desktop-access-05.png)

    1. Fill out the request details. See screenshot for template
![IS portal request details for Citrix Remote Desktop for staff](../../assets/operations/citrix-remote-desktop-access/citrix-remote-desktop-access-06.png)
