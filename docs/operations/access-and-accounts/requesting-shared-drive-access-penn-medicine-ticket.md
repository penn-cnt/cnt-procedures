# Requesting Shared Drive Access (Penn Medicine ticket)

!!! abstract "What this page tells you"
    To get shared drive access, log into the PennMedicine Remote Access Portal, open UPHS Intranet, IS Self Service, Create a Ticket, Access Request Catalog, 'Need Access to Report or Database', and fill the survey with the drive filepath using the provided request wording.

1. Log into PennMedicine Remote Access Portal

[pennmedaccess.uphs.upenn.edu](https://pennmedaccess.uphs.upenn.edu/vdesk/webtop.eui?webtop=/Common/webtop_modern_prod&webtop_type=webtop_full)


2. Click on **UPHS Intranet Page**
3. Click on the red message button that says **IS Self Service**
4. Click on the + sign at the top left that says **Create a Ticket**
5. Click on **Access Request Catalog**
6. Click on the radio button that says **Need Access to Report or Database**, then click **Next**
7. A survey will pop up:
    1. Request Type: **Access Request**
    2. What platform does this access request pertain to? **Other**
    3. Name of Report/application for access: Enter the file path to the drive you need access to
    4. Report ID / Report URL: Enter the file path to the drive you need access to
    5. Request Title: **Requesting Access to Shared Drive (INSERT SHARED DRIVE FILEPATH HERE)**
    6. Additional Information: **Hi, I am a (insert position) in the Department of Neurology and I need access to a drive: (insert filepath name you need access to) to complete my research tasks. Thank you!**
    7. Leave everything else blank and click **submit**
