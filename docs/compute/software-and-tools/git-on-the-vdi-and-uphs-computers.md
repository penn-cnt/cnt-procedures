# Git on the VDI & UPHS Computers

!!! abstract "What this page tells you"
    In the VDI, run Git by opening git-cmd or git-bash from cnt-fs staff_admin/PortableGit. On the Hayden Hall UPHS computer MJ0HKNDA, use GitHub Desktop with cnt-fs mapped as a network drive.

### How to use Git in the VDI (cnt-fs, cnt1)

1. In the VDI, connect to the cnt-fs network drive in File Explorer
2. Go to the `staff_admin/PortableGit` folder, and double click to open either the `git-cmd` or `git-bash` program
    1. `git-cmd` is Windows based terminal, `git-bash` is Linux based terminal
3. This will open a Git-enabled Terminal. In this terminal you can run Git commands

### How to use Git in the Hayden Hall UPHS Computer MJ0HKNDA

1. GitHub Desktop is installed on this computer. Search for this program and launch it. If you want to use Git commands for files in cnt-fs, you will need to make sure it is mapped as a network drive in File Explorer
